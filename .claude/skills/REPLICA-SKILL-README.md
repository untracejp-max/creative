# Replica Skill

The `replica-*` folders here are the Replica Skill pack by Jake Schincariol,
copied unmodified from https://github.com/Jakeschincariol/replica-skill
(commit 77c9436fb3d18c3d58169efb8caf4fe906b0dc51, v1.0.0). MIT licensed; see
`REPLICA-SKILL-LICENSE`.

Run order:

    recon -> architect -> design -> build -> backend -> test -> diff -> entrepreneur -> brand -> launch -> deploy

Each skill is invoked as `/replica-<name>` and shares state through a
`replica/` folder at the project root. The bundled tools need Python 3.8+ and
no extra packages.
